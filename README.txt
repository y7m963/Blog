Travel Blog – Complete Project
==============================

HOW TO RUN
1. Extract this ZIP completely (keep the folder structure).
2. Open the folder in VS Code (File > Open Folder).
3. Install "Live Server" extension if needed.
4. Right-click index.html → Open with Live Server.
   (Do NOT open HTML by double-click – relative paths & scripts need a local server.)

PAGES
- index.html     → Home (Hero, Highlights carousel, FAQ accordion, Contact form)
- article1.html  → Beaches article + 3D card carousel (manual buttons) + charts
- article2.html  → City article + embedded YouTube video (responsive)
- article3.html  → Pattaya article + author section

USER STORIES COVERED
